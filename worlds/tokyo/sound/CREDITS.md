# Tokyo's place sounds: credits

Recordings from [Freesound](https://freesound.org), by the people named below. Each file was made the same way:
Freesound's high-quality preview, cut to the stretch shown, its end crossfaded (3 s) into its start so it loops, its
volume set to match Mundi's own sound for the tag, and encoded as 128 kbps MP3 (see
[`docs/tokyo-sounds.md`](../../../docs/tokyo-sounds.md)). Two are mixes, as noted: `temple.mp3` lays a bell recording
over a temple recording, and `hospital.mp3` adds soft monitor beeps made by Mundi's tools to a recorded room tone.
